How It Works

The Import Process — Seen Through the Planning Manager's Eyes

This is the story of how a crop protection chemical goes from a supplier's factory to a Bangladesh warehouse, and how the two files track it.

End-to-End Process Flow

PO Raised in SAP → LC Opened via Bank → PI Sent to Supplier → Shipping Instructions Sent → Container Booked → Container Sails → Arrives at Port (CTG) → Docs Submitted to Bank → Arrives at Door

BD TRACKER tracks:

  • The PO-level journey (1 row = 1 PO)
  • From PO creation → LC → documents → handover
  • Commercial & compliance milestones
  • Bank interaction (LC, HSBC approval)
  • Document pipeline (9-step milestone chain)
  • Owner: Country Planning Manager

Eagle Eye tracks:

  • The container-level journey (1 PO = many containers)
  • From container pick-up → sailing → port arrival → door delivery
  • Physical logistics milestones
  • Carrier performance & tracking
  • ETA probability & confidence scoring
  • Owner: Logistics / Supply Chain Ops
